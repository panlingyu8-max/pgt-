# EJHF Cover Letter 润色说明

文件：`05_Cover_Letter_EJHF_Polished.docx`（原稿：`05_Cover_Letter_EJHF_Revised_original.docx`）

## 主要改动

1. **开篇直给核心发现**：第一段写明投稿意向，并用一句话交代结论（*FTO* 位点的心衰关联与 BMI 主成分共享，并指向一个与成脂调控 DNA 重叠的单倍型）。
2. **补充临床时效性**：incretin 类药物已在肥胖相关 HFpEF 中显示获益，肥胖因此成为心衰治疗靶点；全基因组 MR 只给出平均效应，无法定位具体位点和生物学过程，这正是本研究的切入点。
3. **三条发现改写为编辑能读懂的表述**：
   - 把 "proportional expectation" 解释为“心衰效应与按全基因组 BMI–心衰关系由其 BMI 效应预测的值最接近”；
   - 明确区分 HERMES 中的 component 级共定位（PP 0.974）与 FinnGen 中的区域级外部支持（PP 0.907），不夸大后者；
   - 补充一句：rs1421085 本身已有实验证据表明可改变脂肪细胞产热。
4. **期刊契合理由具体化**：原句 "should interest EJHF readers" 改为具体理由（肥胖作为心衰治疗靶点 + 位点级遗传证据）。
5. **声明部分**：合并为一段并规范措辞；保留 "not been published in any other journal" 的原有范围，以兼容预印本。AI 使用声明加入 Claude (Anthropic)。
6. **收件人**：改为主编 Professor Michael Böhm。
7. **格式**：沿用原模板；*FTO* 与正文中的期刊名改为斜体；全文压缩到 A4 一页。
