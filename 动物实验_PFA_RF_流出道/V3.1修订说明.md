# V3.0 → V3.1 修订说明

源文件：`build/protocol_v31_keyed.md` → `build/number_refs.py` → `OT_PFA_vs_RF_猪实验方案_V3.1.md` → `build/build.py` → `.docx`。

## 一、按反馈修改

1. **总数固定为12头**：慢性组8头（PFA:RF = 4:4），急性组4头（2:2）。
   - 每组4头的检出能力（标准差1.5 mm，α=0.05，把握度80%）：约3.6 mm（效应量d≈2.4）。每组5头时约为3.0 mm。
   - 每组4头时，Mann-Whitney U检验的最小双侧P值为0.029，只有两组数据完全不重叠才能达到P<0.05。因此主要分析改为基于动物均值的Welch t检验，Mann-Whitney U检验降为敏感性分析，线性混合模型作为病灶层面的支持性分析。
2. **"猪肝"即左主干**：LVOT第1个位点改为"左主干邻近位点"。导管经主动脉逆行置于左冠窦内、左主干开口下方，头端距开口5–8 mm，由ICE短轴/长轴切面和左冠脉造影共同确认，取两者中较小值。5 mm是临床常用安全距离的下限，本方案不在小于5 mm处放电。左主干的造影/QCA和病理评估都单独列出。第2个位点仍为冠状静脉窦远端（心大静脉）。
3. **硝酸甘油只在出现缺血时补救使用**：取消预防性给药。出现缺血性ST改变、低血压或室性心律失常时造影，冠脉内注射100–200 μg，可重复，记录剂量和时间，按不良事件处理。
4. **急性RF组加做右室体部参照点**：在游离壁中段、下壁、心尖部各做1个标准RF点（30 W、60 s），和急性PFA组的低、中、高档位点位置一致，共6个RF病灶，作描述性比较。

## 二、ICE规范化（新增6.3节）

依据：EHRA/EAPCI 2026年ICE科学声明（Peichl等，Europace 2026;28:euag059），以及2019年HRS/EHRA/APHRS/LAHRS室性心律失常消融共识（主动脉窦内消融前以冠脉造影或ICE确定冠脉开口位置；ICE可用于早期发现心包积液）。

- **器械与采集**：相控阵ICE，可与CARTO整合，经左股静脉11F鞘置入，成像频率5–10 MHz。全部操作由同一术者完成；所有图像存储为同步心电图、≥3个心动周期的动态图像，并按统一规则命名。
- **5个标准切面**：home view；RVOT/肺动脉瓣长轴；主动脉瓣短轴（显示左主干开口）；LVOT长轴；左室/心包切面。首头动物记录各切面的导管位置，后续动物按此复现。
- **基线**：将解剖轮廓整合入CARTO并标记左主干开口；在舒张末期垂直心内膜测量各位点壁厚，每点测3次取均值；彩色多普勒对瓣膜反流分级；测量心包间隙作为基线。
- **放电前**：确认导管贴靠方向和稳定性，头端不得压迫瓣叶；测量左主干邻近位点头端至开口的距离。
- **放电中**：RF出现密集爆发样微气泡或蒸汽爆裂时立即停止。PFA放电也可产生微气泡，只记录，不作为停止标准。
- **放电后**：每个位点放电后检查心包；LVOT位点放电后复查主动脉瓣反流；30分钟（急性组另加3小时）及28天复测壁厚和回声改变。
- **局限与质控**：ICE估计病灶深度的准确性有限，ICE壁厚和回声变化只作探索性指标，病理仍为金标准。心大静脉位点以造影定位。ICE离线测量由两名盲态测量者独立完成，并报告组内相关系数。
- 记录表新增：ICE壁厚、贴靠方向、微气泡/蒸汽爆裂、心包积液、各时点瓣膜反流。

## 三、仍需现场核实

- ICE导管型号，以及能否与CARTO整合
- PFA导管能否进入猪心大静脉
- 心大静脉内RF 20 W的阻抗表现
- 猪左冠窦内能否找到距左主干开口5–8 mm的稳定贴靠点。若找不到，按技术排除记录。
