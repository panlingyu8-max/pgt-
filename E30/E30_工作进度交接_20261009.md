1. **AF 分型补充**：未分型者按同次住院基线 TTE 有无 A 峰补全，有 A 峰为阵发性，无 A 峰为持续性。判定依据只写在内部核实文件中，不进入正文和补充材料。

3. **配对分析维持原 844 次手术，不重跑。** 其中团队补录评估纳入的 48 次保留，此前在基线复核中被排除的 9 例恢复纳入。
4. **已删除的内容**：LAAO 探索性分析；Table 4 已并入图 2D。
5. **用词**：cohort 一律改为 set，即 baseline phenotype set、paired response set。
6. **7 例为重复消融**：配对集为 844 次手术、837 例患者。“844 例患者”的说法不成立。
7. **新增联合改善分析（R57，post hoc）**：12 因素与“两瓣均改善”的关系。已写入结果、表 S13、图 4B 图注。

### 2.2 本轮新定（E30b，2026-10-09）——基线人群规则

1. **分析单位为病例**，即消融住院。不区分首次消融和重复消融，7 例重复消融不单独处理。
2. **基线分级来源**：均取自同次住院的 TTE 报告。
   - 电子档案能导出的，用文本解析分级；
   - 未能导出的，用课题组补录到研究登记表的分级。
   - **稿件中只写“基线分级取自同次住院的 TTE 报告”**，不提“补录”。
   - **不得写**“先确认有 1 个月心超、再录入基线心超”。
3. **登记表中二尖瓣、三尖瓣分级均为空白** = 没有基线心超，不纳入。
4. **无电子报告、又无 1 个月心超的登记住院**：不纳入。
5. **不做报告可得性加权，也不做敏感性分析。**
6. **结果**：配对集（844 次）完整包含在基线表型集内，流程图改为单一主干：

```
AF 消融住院（2020.1–2024.9）
  → 有同次住院基线 TTE 分级
  → 统一排除（瓣膜手术 / 器质性瓣膜病 / 先心病 / 梗阻性 HCM）
  → 基线表型集 N 例（阵发性 / 持续性）            → 患病率、表型分析
      → MR 和/或 TR ≥1 级 n 例
          → 无 1 个月 TTE（表 S1B 比较对象）
          → 配对反应分析集 844 次手术（单纯 MR 132 / 单纯 TR 325 / 合并 387；阵发性 343 / 持续性 501）
```
